# ⚡ Electric Vehicle Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive Electric Vehicle (EV) Analysis Dashboard developed using Microsoft Power BI. It provides insights into electric vehicle registrations, vehicle types, manufacturers, model years, geographical distribution, and Clean Alternative Fuel Vehicle (CAFV) eligibility.

The dashboard uses interactive filters and visualizations to help users explore electric vehicle data and identify key trends.

## 🎯 Project Objectives

- Analyze electric vehicle registration data.
- Compare Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
- Explore vehicle trends across different model years.
- Identify leading electric vehicle manufacturers.
- Analyze the geographical distribution of electric vehicles across states.
- Examine CAFV eligibility categories and popular vehicle models.

## 📊 Dashboard Highlights

### 1. Key Performance Indicators (KPIs)
- Total Vehicles: approximately 150K
- Average Electric Range: approximately 67.83 km, as displayed in the dashboard
- Battery Electric Vehicles (BEVs): approximately 117K
- Plug-in Hybrid Electric Vehicles (PHEVs): approximately 34K

### 2. Vehicle Trends by Model Year
A line chart illustrates changes in electric vehicle registrations across model years, helping identify growth patterns and year-wise trends.

### 3. Geographical Distribution
A map visualizes the distribution of electric vehicles across US states.

### 4. Manufacturer Analysis
A bar chart compares manufacturers, highlighting Tesla, Nissan, Chevrolet, Ford, BMW, Kia, and other brands.

### 5. CAFV Eligibility Analysis
A doughnut chart presents the distribution of vehicles across Clean Alternative Fuel Vehicle eligibility categories.

### 6. Vehicle Model Analysis
A treemap compares popular electric vehicle models, including Model Y, Model 3, Leaf, Bolt EV, and others.

### 7. Interactive Filters
Users can filter the dashboard by:
- City
- Electric Utility
- Electric Vehicle Type
